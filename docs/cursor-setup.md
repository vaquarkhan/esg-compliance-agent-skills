# Cursor setup

1. Clone the repository
2. Run `bootstrap.ps1` or `bootstrap.sh`
3. Copy `mcp/esg-mcp-servers.mcp.json` into Cursor MCP settings
4. Rules load from `.cursor/rules/esg-compliance.mdc`
5. Lifecycle commands: `.claude/commands/*.md`

Read [AGENTS.md](../AGENTS.md) before loading skills.

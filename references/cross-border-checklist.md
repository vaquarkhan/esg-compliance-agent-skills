# Cross-border transfer checklist

- [ ] Data classified (personal / sensitive / non-PII)
- [ ] Origin and destination jurisdictions documented
- [ ] DPDP / PIPL / PDPL rules fetched via MCP
- [ ] Transfer mechanism documented (SCC, adequacy, consent, or block)
- [ ] DPO sign-off recorded
- [ ] In-region AWS replication only where required

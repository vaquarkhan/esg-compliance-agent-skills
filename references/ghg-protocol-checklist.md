# GHG Protocol inventory checklist (operational subset)

- [ ] Organizational boundary documented (operational control or equity share)
- [ ] Scope 1 stationary and mobile combustion calculated with cited factors
- [ ] Scope 2 location-based using country grid factor + year
- [ ] Scope 2 market-based only with attested REC/PPA documentation
- [ ] Scope 3 material categories with data quality tier
- [ ] IPCC AR6 GWP100 applied consistently
- [ ] `factor_provenance.json` complete
- [ ] Human reviewer sign-off before external disclosure
